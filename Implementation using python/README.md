# Simple Hospital Management System

Open `simple_hospital.py` in VS Code and choose **Run Python File in Terminal**, or run:

```powershell
python simple_hospital.py
```

Choose **1** for the class demonstration and **0** to exit.
You can also press **F5** and select **Simple Class Demonstration**.

Read `CLASS_PRESENTATION.md` for your speaking script and code explanations.
Python 3.10 or newer is required. No extra packages are needed.
Data clears when the program closes.
